# 家庭おでんの研究ノート

大人4人分。前日15時開始、翌日19時提供、全28時間。家庭用2口コンロで、鰹が香る淡口のつゆ、中心まで味のある大根、軟らかい牛すじ、弾力の残る練り物を目指す。文献から組み立てた初回試作用の配合で、完成品の試食・塩分測定は未実施。

## 買い物と道具

- 利尻昆布30g、本枯節の血合い抜き薄削り51g、軟水2,700ml。下茹で用の水は別。
- 清酒40ml（食塩無添加）、本みりん30ml、淡口醤油35ml、塩10.5g。こんにゃく用の塩2g、からし8g。砂糖・濃口醤油は各0g。
- 大根中央部は皮を除いて約480g、脂塊の少ない生牛すじ350g、M卵4個、板こんにゃく200g、焼きちくわ120g（2本）、平天160g（薄手4枚）。
- 仕上げ鍋約5L、牛すじ用鍋2〜3L、小鍋、温度計、はかり、濾し布、浅い金属容器、氷。冷蔵庫に容器を一段に置ける場所を作る。

**出汁**は昆布と鰹を抽出した無調味の液。**基本つゆ**は出汁に酒、みりん、醤油、塩を加えたもの。醤油の食塩相当量が2.8g／15mlなら基本つゆは計算上約0.81g／100ml。銘柄を変える場合の添加塩は「17.0 − 醤油15ml当たりの食塩相当量 × 35 ÷ 15」g。完成時には具の水分・塩分・蒸発が影響する。

## 仕込み工程

時刻は目安。温度と串の通りを優先する。前日はAで牛すじ、Bで出汁とほかの具を扱う。

1. 前日15:00–15:30、A。牛すじを水1,500mlから加熱。沸いて3分で湯を捨て、肉と鍋のアクを落とす。肉を2.5〜3cm角に切る。
2. 15:00–16:15、B。軟水2,700mlと利尻昆布30gを約15分で60℃へ上げ、到達後58〜62℃で60分保持。昆布を引き上げる。
3. 15:30–18:15ごろ、A。1の肉に新しい水1,200ml。アクを取り、15:45ごろから90〜95℃。露出しそうなら熱湯100mlずつ補う。17:15から白いすじを串で確認し、たわんで形を保つところで14へ。硬ければ20分ずつ延長。
4. 15:45–16:00。大根を厚さ2cmの輪切り8枚にし、皮を2〜3mmむく。角を軽く落とし、片面に深さ4〜5mmの十字を入れる。
5. 16:00–16:15。節を45gと6gに分け、当日用6gを密封。調味料を計量し、氷水と保存容器を用意。
6. 16:15–16:28、B。2の昆布出汁を85〜88℃にし、火を止めて5の節45gを入れる。90秒で自然に濾す。無塩出汁250mlを20の調整用に急冷・冷蔵。
7. 16:28–16:58、B。4の大根を水1,500mlから下茹で。沸いて12〜20分で、串が中心だけ軽く止まる状態を確認し、ざるへ。
8. 16:58–17:08、B。5の清酒・みりんを沸かして1分。醤油・塩を溶かし、6の出汁を加え、**調味料込みで2,100ml**にしてひと煮立ち。9に1,100ml、13に300ml、16に500ml、19に200ml。後の3口はすぐ別容器で急冷。
9. 17:08–17:45ごろ、B。7の大根を8のつゆ1,100mlに入れ、落とし蓋。85〜90℃で25〜35分。串が中心まで通り、持ち上げても割れなければ終了。煮汁約300mlを12用に分け、残りは大根と一緒に浅い容器で即座に急冷。
10. 17:20–17:35。こんにゃくを厚さ1.2cmの三角8切れに。片面に深さ2mm、間隔5mmの格子を入れ、塩2gでもんで5分置き、洗う。
11. 17:45–17:55、B。10のこんにゃくを湯800mlで2分下茹でし、水を切る。
12. 17:55–18:10、B。11を9で取った煮汁約300mlに入れ、85〜90℃に戻して約10分。汁ごと急冷。
13. 18:10–18:45、B。水1,000mlを沸かし、M卵を入れて11分茹でる。氷水で約10分冷やしてむき、8の冷たいつゆ300mlに浸して冷蔵。
14. 3が軟らかくなった時点（標準18:15）。煮汁を濾し、肉には乾燥防止の汁をかける。澄んだ煮汁を別容器に150ml以上確保し、肉も汁も直ちに急冷。
15. 各品の火止めごとに実施。6・8・9・12・14は浅い容器と氷水で、60分以内に厚い具の中心を10℃以下にする目標。氷を交換し、冷えた順に4℃以下設定の冷蔵庫へ。大根・こんにゃく・卵は汁に約24時間浸す。
16. 当日17:55–18:15。9と12の具を取り出し、両方の煮汁、8のつゆ500ml、14の脂・沈殿を除いた煮汁120mlを本鍋で一度沸かす。
17. 18:15–18:40。16に9の大根、12のこんにゃく、14の肉を入れ85〜90℃へ。厚い具の中心75℃以上で1分を確認。ちくわを計8切れにし、平天には熱湯500mlをかける。
18. 18:40–18:55ごろ。13の卵を漬け汁から出し、半割りにして17へ。18:43に17で準備したちくわ・平天を入れる。卵と厚い具の中心も75℃以上で1分を確認。
19. 18:48–18:55、別鍋。8のつゆ200mlを沸かし、85〜88℃で5の節6gを加える。60秒で濾す。18が仕上がったら本鍋の火を止め、追い鰹のつゆを合わせる。
20. 18:55–19:00。19の汁と大根中心を味見。濃ければ6の無塩出汁を再加熱し、汁1Lに50mlずつ加える。温めた器に具を4等分し、汁120〜150mlと別添えのからしを用意。

## 技法の比較と判断

- 上野直哉氏は二度目の牛すじの茹で汁を活用する。今回は別煮し、冷やして脂を外すことで、肉の軟化時間と本鍋の肉香を別々に調整する。手羽先は省く。[上野氏のレシピ](https://www.kyounoryouri.jp/recipe/10302_%E3%81%8A%E3%81%A7%E3%82%93.html)
- 野﨑洋光氏は練り物から先に出汁を取り、一度取り出して終盤に戻す。今回は昆布・鰹・牛があるため、練り物は最後の約12分。煮続けて魚の味が抜けるのを避ける。[野﨑氏のレシピ](https://www.kibun.co.jp/recipes/22081/index.html) ／ [農水省のおでん解説](https://www.maff.go.jp/j/keikaku/syokubunka/culture/wagohan/articles/2302/spe14_02.html)
- たこ梅は大根に2日、こんにゃくに4日かける例を紹介。家庭では厚さ・隠し包丁・汁中冷蔵で一口の味を整える。お多幸の濃い東京風も選択肢だが、今回は汁を飲む前提で淡口にする。[たこ梅](https://takoume.jp/category/media) ／ [東京都のお多幸取材](https://www.tokyoupdates.metro.tokyo.lg.jp/post-1882/)
- 塩の拡散は温度が高いほど速く、冷却そのものに特別な促進効果は確認されていない。大根を汁中で休ませる時間を確保し、冷却は速くする。脂やコラーゲンと塩の分布は同じとは限らない。[調理科学会誌・温度と拡散](https://www.jstage.jst.go.jp/article/cookeryscience/45/2/45_133/_pdf) ／ [大根の加熱・保存](https://www.jstage.jst.go.jp/article/cookeryscience/44/1/44_64/_article/-char/ja/)
- 利尻は澄んだ風味、真昆布は上品な甘み、羅臼は濃厚、日高は軟らかく具にも向く。代替の第一候補は真昆布30g。今回は昆布のグルタミン酸と鰹のイノシン酸を組み合わせる。荒節は燻香、宗田節・さば節・煮干しは魚の風味、干し椎茸はグアニル酸と独特の香りを加えるため、採否は完成時の香りで決めた。[昆布の種類](https://www.maff.go.jp/j/keikaku/syokubunka/culture/attach/pdf/haifu-35.pdf) ／ [だし素材](https://www.maff.go.jp/j/pr/aff/2611/spe1_01.html) ／ [うま味の相乗効果](https://www.ncc.go.jp/jp/ncce/CHEER/point/030/index.html)
- 軟水の目安は硬度20〜60mg/L。硬度比較では昆布のグルタミン酸にわずかな低下傾向、鰹のイノシン酸はほぼ一定だった。[硬度比較研究](https://www.saltscience.or.jp/images/2023/07/201569.pdf)
- **冷蔵12時間の水出しと60℃・1時間。** 真昆布・日高昆布の比較では、水出しと加熱抽出で香気成分の構成が異なり、昆布の種類の差はどちらでも識別された。12時間が全素材の最適値という結論は出ていない。今回の利尻には工程2を採用。磯の香りの好みで評価は変わる。参照動画の発言前後は未確認。[2023年学会発表](https://www.jstage.jst.go.jp/article/ajscs/34/0/34_94/_article/-char/ja/) ／ [昆布の抽出法](https://www.umamiinfo.jp/what/tasting/know.html) ／ [話題になった動画](https://youtu.be/wKSFRQN5NNM)
- 急冷は厚労省の大量調理向け基準を家庭の目標に応用。室温で一晩置かず、翌日の再加熱は厚い具の中心を測る。[大量調理施設衛生管理マニュアル](https://www.mhlw.go.jp/web/t_doc?dataId=00tb9161&dataType=1&pageNo=1) ／ [家庭でできる食中毒予防](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/01_00006.html)

## 試作で確かめること

汁、大根の中心、牛すじ、平天、もう一度汁の順に味見する。大根の芯が薄ければ半月に割り、次回は厚さ1.7〜1.8cm。牛すじが硬ければ別鍋で20分延長。汁がぼやけ、香りは十分なら塩を1Lに0.3gずつ。油膜はすくい、沈殿は上澄みを濾す。練り物が膨れて味が抜けたら次回は3〜5分短縮し、中心加熱を確認する。

牛の煮汁120mlと追い鰹6gは設計値。牛すじの個体差を確認するには、基本つゆ50mlずつに牛の煮汁3mlと6mlを加え、同温で比較する。飲み込んだ後の鰹と牛の余韻を記録する。
